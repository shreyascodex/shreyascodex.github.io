# ⚙️ Getting Started

### Clone

```bash
git clone https://github.com/shreyascodex/portfolio.git
```

### Install

```bash
pnpm install
```

### Run

```bash
pnpm run dev
```

Open:

```
http://localhost:5173
```

---

# 📧 Contact Form

This portfolio uses **EmailJS** to send messages directly from the website.

Replace the following values inside:

```text
src/components/sections/Contact.tsx
```

- Service ID
- Template ID
- Public Key
